Use fewer tokens without losing quality

A cross-provider evidence review and a practical plan for Codex in VS Code across multiple workspaces and machines.

This report recommends changes. The separate weekly dashboard measures usage trends; neither local token logs nor one benchmark can prove cost effectiveness by themselves.

What the evidence says

Harness and tool contextDatabricks saw over twice the cost with the same model and quality in some harness comparisons.Inspect enabled MCP servers and their tool context. Their actual token contribution has not been measured.
Measure accepted workStanford found large run-to-run token variation and weak correlation between more tokens and accuracy.Compare repeated, similar tasks using total cost per accepted result, elapsed time, and human repair time.

Studies use different tasks and systems. Their findings guide trials; they do not establish savings in your repositories.

What has been measured here

One narrow A/B lookup task was answered correctly by both setups. The shorter instruction setup used 34% less total input and 54% less uncached input. This is promising evidence for context reduction, not a coding-workflow benchmark. Specialist routing, actual charges, and quality over repeated tasks have not been measured.

How to produce work going forward

  1. Install the portable kit on each machine with ./scripts/install.sh --codex-efficiency. Keep organization-specific instructions in their own repository or managed profile. Start a fresh Codex chat with the matching profile.
  2. Give Codex the task and success criteria. Let it choose direct work or one bounded specialist handoff; require it to verify specialist output.
  3. Use the separate weekly dashboard for an eight-week token trend. Enter accepted tasks and repair minutes in the local codex-efficiency-outcomes.csv file, starting from the bundled template to see per-accepted-task proxies; otherwise the dashboard marks effectiveness as unmeasured. Count retries across all agent calls.
  4. For a real benchmark, repeat a code search, routine edit, and higher-risk change under the old and new setups. Compare cost per accepted task and quality, including all calls and repair.
  5. Check the actual Codex allowance, service tier, and charges in the provider usage view. Local credit equivalents are estimates, not a bill.
